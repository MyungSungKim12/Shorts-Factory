# 단어 소재 추천 및 대본 정보량 개선 설계

## 목표

짧은 단어 소재는 곧바로 탈락시키지 않고 제작 가능한 영상 기획 후보로 확장한다. 자동·수동 스토리 대본은 검증된 사실을 충분히 전달하도록 최소 정보량과 서사 구성을 보장한다.

## 단어 소재 추천

- 질문이나 구체 조건이 없는 짧은 입력은 단어 소재로 판정한다.
- 검색 그라운딩 한 번에서 3~5개의 서로 다른 기획과 각 기획의 완전한 사실 계약을 요청한다.
- 각 후보는 안전성, 서로 다른 출처 2개, 스키마, 채널 적합성, 무료·재사용 AI·신규 AI 시각 자료 메타데이터를 검사한다.
- 제작 가능한 후보를 점수순으로 최대 3개 표시한다.
- 후보가 2개 미만이면 기존 후보를 제외하고 한 번만 추가 생성한다.
- 후보 선택은 저장된 검증 결과를 원자적으로 `reservable` 상태로 전환하며 추가 LLM 호출이나 미디어 다운로드를 하지 않는다.
- 후보가 없거나 사용자가 확정하지 않으면 기존 회차 자동 생성 경로를 유지한다.

## 대본 정보량

- 스토리 본문은 8~10개 장면, 나레이션 320~440자, 장면 길이 합계 60~68초를 목표로 한다.
- 제목 음성 인트로와 CTA를 포함한 최종 영상은 약 70~85초 범위를 목표로 하며 90초를 넘지 않는다.
- 배경, 구체적 기록, 기묘한 이유, 설명 또는 원리, 불확실성, 의미를 서로 다른 정보 단위로 다룬다.
- `알아보겠습니다`, `살펴보겠습니다`, `확인해 보겠습니다`처럼 내용 없이 다음 설명을 예고하는 문장은 금지한다.
- 최소 글자 수, 필수 역할, 금지 문구를 코드 계약에서 검사하여 프롬프트 편차를 막는다.
- 모델 응답이 실패하면 한 번 재작성하고, 계속 실패하면 검증된 topic 필드만 사용하는 기존 템플릿으로 회차를 유지한다.

## 기존 동작 보존

- 구체적인 문장 소재는 기존 직접 검증 경로를 사용한다.
- 수동 검증 실패·미확정은 정시 자동 제작을 막지 않는다.
- 자동 4회 일정, 승인·반려·업로드 및 일 6건 제한은 변경하지 않는다.
