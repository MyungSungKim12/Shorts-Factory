# 실패 회차 자동 소재 복구 설계

## 목표

수동 소재 검색이나 제작이 실패한 회차에서 운영자가 `자동 소재로 전환`을 누르면 수동 게이트를 제거하고 기존 자동 제작·업로드 흐름으로 복귀한다.

## 동작

- 대상 상태는 작업자가 없는 `draft`, `checking`, `needs_input`, `reservable`, `reserved`, `failed`, `rejected`, `skipped`다.
- 수동 예약 행을 트랜잭션으로 삭제해 `upload_decision()`이 기존 `automatic` 경로를 선택하게 한다.
- 제작 시작 전이면 별도 작업 없이 기존 제작 cron을 기다린다.
- 제작 시작 이후이면서 업로드 전이면 해당 run_id를 즉시 사전제작하고 기존 업로드 cron이 올린다.
- 업로드 시간이 지났으면 해당 run_id의 전체 자동 파이프라인을 즉시 실행한다.
- 활성 worker가 있거나 검토·승인·업로드 단계인 회차는 전환을 거부한다.
- 삭제 뒤에도 이벤트 조회는 유지해 화면에서 자동 전환과 후속 실패 원인을 확인할 수 있게 한다.

## API와 화면

- `POST /api/slots/{run_id}/automatic`은 관리자 토큰이 필요하다.
- 응답은 `mode=auto`, `state=auto`, `automatic_action=scheduled|prebuild|immediate`를 포함한다.
- 실패·추가입력·예약·건너뜀 상태의 수동 카드에 `자동 소재로 전환` 버튼을 표시한다.

## 안전성

- 기존 전역 파이프라인 잠금, 준비 산출물 검증, YouTube 중복 검사와 일 6건 제한을 그대로 사용한다.
- 새 경로는 영상 파일이나 기존 업로드 기록을 삭제하지 않는다.
