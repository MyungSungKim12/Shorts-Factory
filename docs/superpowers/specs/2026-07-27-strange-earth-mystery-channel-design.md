# 이상한 지구기록 채널 전환 설계

## 목표

하루 4회 스토리를 검증 가능한 지구 미스터리로 통일하고 동물 중심 소재를 제거한다. 생성 목표는 60~75초로 유지하되 실제 TTS가 길면 최종 180초까지 허용한다.

## 회차

- slot 1, 11시: 기묘한 자연 현상 (`place_nature`)
- slot 4, 14시: 과학의 경계와 미해결 관측 (`science_mystery`)
- slot 2, 17시: 숨겨진 세계와 금지된 구조 (`hidden_world`)
- slot 3, 21시: 사라진 문명과 역사 미스터리 (`history_mystery`)

## 안전 기준

- 확인된 사실과 아직 설명되지 않은 부분을 구분한다.
- 초자연적 결론을 사실처럼 단정하지 않는다.
- 동물을 주인공이나 핵심 반전으로 삼지 않는다.
- 기존 `animal_survival` 캐시는 선택하지 않는다.
- 실패한 2회차는 새 프롬프트로 다시 생성하며 기존 실패 staging은 재사용하지 않는다.
