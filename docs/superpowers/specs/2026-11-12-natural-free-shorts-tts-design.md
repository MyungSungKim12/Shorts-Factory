# 무료 쇼츠 음성 자연스러움 개선 설계

## 의도

무료·로컬 자동화를 유지하면서 현재 F3 아나운서 음색, 이중 속도 보정, 장면별 음량 보정과 일정한 장면 사이 공백에서 생기는 기계적인 인상을 줄인다.

## 목표

- Supertonic 3의 성인 여성 `F4`를 기본 음성으로 사용한다.
- 목표 발화 속도 1.2배는 모델의 기본 합성 속도로 만들고, 이미 적용된 속도를 다시 FFmpeg로 가속하지 않는다.
- 공급자별 실제 생성 속도를 기준으로 필요한 오디오만 후처리한다.
- 장면마다 개별 음량을 바꾸지 않고, 전체 내레이션 트랙을 한 번 정규화한다.
- 장면 사이의 인위적인 무음을 줄이되 자막·영상 싱크 구조는 유지한다.

## 비목표

- 소재 선정, 영상 소스, 자막 디자인, 업로드 일정은 변경하지 않는다.
- 새 유료 API나 강제 정렬 모델을 추가하지 않는다.
- 전체 본문을 한 파일로 합성해 단어 단위 정렬하는 대규모 구조 변경은 이번 범위에 포함하지 않는다.

## 접근법

1. **선택: 현재 Supertonic 파이프라인을 보정한다.** 추가 비용과 서비스 의존성이 없고 현재 자동 공장에 가장 안전하다.
2. CapCut 음성은 무료 상업 이용이 가능하지만 공개 서버 API가 없어 자동 공장에 적합하지 않다.
3. Google Chirp 3 HD는 자연스럽지만 결제 계정이 필요하며 무료 로컬 운영이라는 이번 제약과 맞지 않는다.

## 동작

- Supertonic 기본값: `F4`, 모델 합성 속도 `1.2`, 문장 내부 기본 무음 `0.08초`.
- 목표 속도와 TTS 결과의 실제 합성 속도 비율로 후처리 배속을 계산한다. 비율이 1이면 재인코딩하지 않는다.
- 개별 WAV 생성 단계에서는 앞뒤 무음만 정리한다.
- 최종 영상 합성 단계에서 완성된 내레이션 오디오 전체에 `-16 LUFS` 정규화를 한 번 적용한 뒤 배경음과 전환음을 섞는다.
- 장면의 끝 여유는 0.15초에서 0.06초로 줄인다.

## 안전 조건

- Supertonic 실패를 gTTS로 숨기지 않는다.
- Supertonic과 기존 gTTS가 함께 설치되도록 `huggingface-hub 0.36.0`, `click 8.1.8` 호환 조합을 고정한다.
- Google·Gemini 폴백 경로는 기존 공급자별 속도 값을 이용해 목표 속도를 유지한다.
- 최종 길이 90초, 오디오 실측 기반 자막 싱크, 제목·CTA 1회 규칙은 유지한다.
