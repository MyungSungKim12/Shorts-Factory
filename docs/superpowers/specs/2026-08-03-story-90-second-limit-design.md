# 스토리 영상 90초 제한 설계

## 목표

스토리 영상은 70~80초를 목표로 작성하고, 제목 인트로와 CTA를 포함한 최종 영상이 90초를 넘지 않도록 한다.

## 범위

- 스토리 작가 프롬프트에 본문 나레이션 전체 400자 이하, 장면당 55자 이하를 명시한다.
- `StoryScriptContract`가 동일한 글자 수 제한을 검증한다. 초과 응답은 기존 작가 재시도와 검증 템플릿 경로를 사용한다.
- 실제 TTS 합계가 90초를 조금 넘으면 음높이를 유지한 채 최대 1.12배까지만 속도를 높인다.
- 보정 후에도 최종 길이가 90초를 넘으면 제작을 중단한다.
- 운영 환경의 `MAX_VIDEO_SEC`를 90으로 설정해 제작·품질검사·업로드가 같은 상한을 사용하게 한다.

## 길이 산정 근거

2026-08-03 2회차 영상은 본문 604자, 제목 24자, CTA 40자로 최종 117.6초였다. 같은 발화 밀도를 기준으로 본문을 400자 이하로 제한하면 제목과 CTA를 포함해 약 80초 전후가 되며, 음성별 편차는 제한된 속도 보정과 최종 90초 검증으로 흡수한다.

## 실패 처리

- 글자 수 초과: 작가 단계에서 거부하고 기존 1회 재생성을 수행한다.
- 실제 음성이 90초 초과지만 1.12배 이내 보정 가능: 필요한 만큼만 속도를 높인다.
- 1.12배보다 빠른 보정이 필요: 부자연스러운 음성을 만들지 않고 제작 실패로 처리한다.

## 제외 범위

소재 선정, 영상 소스, Veo, 자막, 업로드 일정, 크레딧 전환 및 기타 에이전트 로직은 변경하지 않는다.

## 검증

- 400자 초과 스토리 대본 계약 거부
- 장면당 55자 초과 거부
- 90초 이하 음성 무보정
- 소폭 초과 음성의 제한된 속도 보정
- 1.12배 초과가 필요한 음성 거부
- 전체 테스트 통과 후 서버 배포 및 21시 패키지 생성 결과가 90초 이하인지 확인
