# 크레딧 인식형 프리미엄 영상 생성 설계

## 목표

Google Cloud 무료 체험 크레딧을 소재 선정, 내레이션, AI 오프닝 품질에 집중 사용한다. 예상 잔액이 80,000원 이하가 되거나 크레딧 만료 안전 시점에 도달하면 신규 유료 호출을 중단하고 기존 무료 파이프라인으로 자동 전환한다.

## 운영 모드

- `auto`: 비용 원장과 설정값으로 프리미엄/무료 모드를 결정한다.
- `premium`: 운영자가 명시적으로 프리미엄을 강제한다. 단, 잔액 하한과 만료 안전장치는 우회하지 않는다.
- `free`: Vertex Gemini, Gemini TTS, 신규 Veo 호출을 하지 않는다.
- 무료 모드에서도 검증을 통과해 영구 저장된 동일 대상 AI 영상은 재사용한다. 일치 자산이 없으면 무료 스톡으로 폴백한다.

## 비용 가드

- 시작 예상 잔액: 서버 환경변수 `CLOUD_CREDIT_START_KRW=460418`
- 자동 전환 하한: `CLOUD_CREDIT_FLOOR_KRW=80000`
- 원장: `data/billing/ai_spend.jsonl`
- 상태: `data/billing/credit_state.json`
- 성공한 유료 호출만 모델, 단가, 수량, 원화 환산액, run_id와 함께 기록한다.
- 호출 전에 예상 비용을 예약해 하한을 넘는 호출을 막고, 실패하면 예약을 취소한다.
- 원장 또는 상태 파일이 손상되거나 오래되어 신뢰할 수 없으면 무료 모드로 실패 안전 전환한다.
- Telegram에는 최초 모드 전환과 일일 비용 요약만 보내 중복 알림을 막는다.

## 프리미엄 생성

1. 리서처와 작가는 Vertex Gemini 2.5 Flash를 우선 사용한다. 실패하거나 무료 모드이면 현재 Gemini API/Groq/캐시 체인을 그대로 사용한다.
2. 내레이션은 Gemini 2.5 Flash TTS의 여성 `Kore`와 미스터리 다큐멘터리 스타일 프롬프트를 사용한다. 실패하거나 무료 모드이면 현재 Chirp 3 HD Kore, 마지막으로 gTTS를 사용한다.
3. 검증된 실제 이미지가 있으면 Veo 3.1 Fast 후보를 최대 2개 생성한다. 기준 이미지 일치도, 밝기, 검증 실패 수로 우수 후보를 고른다.
4. 모든 후보와 메타데이터는 `data/media/ai_openings/`에 보존한다. `ready` 자산만 재사용한다.
5. 동일 대상은 검증된 출처 URL과 정규화된 대상 키로 찾는다. 단순히 비슷한 장소라는 이유로 실제 대상 영상을 재사용하지 않는다.

## 저장공간

현재 루트 디스크는 45GB 중 약 34GB가 남아 있고 AI 라이브러리는 92MB다. 자산은 7일 작업폴더 정리에서 계속 제외한다. 디스크 사용률 75% 또는 AI 라이브러리 10GB 도달 시 삭제하지 않고 Telegram 경고를 보낸다.

## 17시 회차 교체

- 기존 `20260803-2` 패키지를 서버 백업 폴더에 보존한다.
- 새 코드 배포 후 같은 회차를 staging에서 다시 생성한다.
- 새 패키지가 전체 품질 게이트를 통과한 경우에만 기존 work 패키지를 원자적으로 교체한다.
- 17시 전에 완료되지 않으면 기존 영상을 자동 업로드하지 않도록 해당 회차를 보류하고, 새 영상 완료 직후 수동 예약 실행으로 업로드한다.
- 새 생성이 실패하면 기존 패키지를 복원할 수 있으며 자동 삭제하지 않는다.

## 검증

- 비용 하한, 예약/확정/취소, 손상 원장 무료 전환 테스트
- 무료 모드에서 신규 Vertex/Veo 호출 금지 및 저장 자산 재사용 테스트
- Vertex 실패 시 기존 공급자 폴백 테스트
- Gemini TTS 실패 시 Chirp/gTTS 폴백 테스트
- Veo 후보 2개 선택·영구 저장·품질 점수 테스트
- 전체 pytest와 서버 품질 게이트 통과 후 배포
