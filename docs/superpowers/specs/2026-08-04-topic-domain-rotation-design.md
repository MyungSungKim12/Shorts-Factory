# 소재 영역 순환 및 중복 방지 설계

## 목표

하루 4회와 기존 두 상위 카테고리(`science_mystery`, `hidden_world`)는 유지하면서 우주·심해·빙하 편중과 표현만 달라진 동일 소재의 재사용을 줄인다. 모델 호출 횟수는 늘리지 않는다.

## 영역 순환

과학 미스터리는 `대기·기상 → 지질·극한 자연 → 우주·천문 → 변칙 물리·기술`을 순환한다. 숨겨진 세계는 `고대 구조·기술 → 지하·금지 시설 → 바다·심해 → 빙하·극지`를 순환한다.

날짜 홀짝과 회차를 조합해 하루 네 영상이 서로 다른 영역을 사용하고, 이틀 동안 여덟 영역을 한 번씩 사용한다. 기존 과학/숨겨진 세계 교차 편성은 유지한다.

## 중복 방지

최근 14일 DB 조회에서 `title`뿐 아니라 실제 `topic`도 함께 읽어 모델 프롬프트와 검증 캐시 제외 목록에 전달한다. 따라서 제목이 바뀌어도 같은 캐시 소재를 다시 고르는 문제를 차단한다. 프롬프트에는 최근 소재와 핵심 대상·사건·관측값이 같은 후보도 제외하도록 명시한다.

## 실패 처리

영역 순환은 소재 선택의 방향이지 추가 API 호출 조건이 아니다. 후보 점수가 낮아도 기존처럼 한 번의 호출에서 최고 후보를 선택하며, 그라운딩 실패 시 같은 영역의 검증 캐시 또는 보수 모드로 진행한다.

## 검증

- 최근 이력 로더가 제목과 실제 소재를 모두 반환한다.
- 날짜와 회차에 따라 하루 네 영역이 중복되지 않는다.
- 이틀 동안 여덟 영역이 모두 한 번씩 선택된다.
- 프롬프트에 선택 영역과 의미 중복 금지 규칙이 포함된다.
- 기존 전체 테스트가 통과한다.
