# 무료 그라운딩 복구와 로컬 여성 TTS 설계

## 목표

Gemini 무료 검색 할당량이 소진돼도 신규 소재를 검색 검증하여 하루 4회 자동 파이프라인이 중복 후보 하나 때문에 중단되지 않게 한다. 불안정한 비공식 Edge TTS와 남성처럼 들리는 gTTS 폴백을 제거하고, 무료 로컬 여성 음성으로 고정한다.

## 설계

- 그라운딩 우선순위는 Vertex(유료 모드일 때) → Gemini 검색 → Groq GPT-OSS 브라우저 검색이다.
- Groq 검색은 검색 근거 메모를 만든 뒤 일반 JSON 호출로 기존 산출물 계약에 맞춘다.
- 리서처는 검색 결과가 중복이면 제외 사유를 다음 프롬프트에 넣고 최대 3회 새 후보를 요청한다.
- 중복 판정 규칙과 `verification_method` 기록은 유지한다.
- 무료 TTS는 Supertonic 3의 한국어 여성 F3 음성을 CPU에서 실행한다.
- Supertonic 실패 시 gTTS로 폴백하지 않고 제작을 실패시켜 잘못된 음성 업로드를 막는다.
- 모델 자산은 서버 배포 시 미리 다운로드하며 이후 합성은 로컬에서 수행한다.

## 비목표

- 크론 시간과 하루 4회 구조 변경
- 기존 업로드 소재의 중복 허용
- 유료 Google/Azure TTS 활성화
- 영상 레이아웃·자막·업로더 변경
