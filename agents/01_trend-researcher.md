# 소재 리서처 (Trend Researcher) — 스토리 포맷

## 역할

`이상한 지구기록`의 방향에 맞춰, 무료 영상으로 표현할 수 있으면서 사람들이 제목만 보고도 결말을 궁금해할 검증 가능한 과학 미스터리와 숨겨진 세계 소재를 고른다. API 호출을 늘리지 않기 위해 한 번의 모델 호출 안에서 후보 8개를 비교하고 최고점 소재 하나만 출력한다.

## 입출력 계약

- 입력: 회차별 스토리 방향, 최근 14일 소재, 검색 그라운딩 사용 가능 여부
- 출력: `data/work/{run_id}/topic.json`
- 실제 계약 구현: `app/models.py`의 `StoryTopicContract`
- 실제 실행 프롬프트: `app/agents/researcher.py`의 `_story_researcher_prompt()`

## 수동 단어 소재 처리

- 사용자가 `오디세이아`처럼 단어만 입력하면 곧바로 탈락시키지 않는다.
- 같은 단어에서 만들 수 있는 서로 다른 핵심 질문을 검색 검증하고, 사실 출처와 시각 자료가 모두 확보되는 후보만 최대 3개 제시한다.
- 후보마다 무료 실제 자료, 재사용 가능한 AI 자료, 필요 시 새 AI 인트로 가능 여부를 사전 확인한다.
- 후보가 부족하면 한 번만 추가 탐색한다. 마감까지 선택·예약되지 않으면 기존 자동 소재 선정이 그대로 실행된다.

## 소재 선정 기준

후보마다 다음 항목을 0~5점으로 평가한다.

1. 첫 3초 호기심
2. 상식 반전
3. 위험·규모·충격
4. 남성 시청자 관심도
5. 무료 스톡 확보 가능성
6. 최근 소재와의 차별성

24/30 이상을 목표로 한다. 목표 점수에 못 미쳐도 재호출하거나 회차를 중단하지 않고 최고점 후보를 선택한다.

## 회차 방향

- slot 1(11시): 과학의 경계와 미해결 관측
- slot 2(14시): 숨겨진 세계와 금지된 구조
- slot 3(17시): 과학의 경계와 미해결 관측
- slot 4(21시): 숨겨진 세계와 금지된 구조
- 과학 방향은 대기·기상, 지질·극한 자연, 지구 기록·탐사 이상, 변칙 물리·기술을 순환한다.
- 숨겨진 세계 방향은 고대 구조·기술, 지하·금지 시설, 버려진 장소·제한 구역, 빙하·극지를 순환한다.
- 하루 네 회차는 서로 다른 하위 영역을 사용하고, 이틀 동안 여덟 영역을 한 번씩 사용한다.
- 우주·천문과 바다·심해는 최근 과다 노출 영역으로 취급한다. 자동 소재에서는 선택하지 않고, 수동 예약에서만 사용자가 명확히 원할 때 검증 후 다룬다.
- 암흑물질, 블랙홀, 우주론, 은하, 행성 대기, 금성 대기, 타이탄·토성 같은 추상 우주·천문 소재는 자동 제작에서 제외한다.
- 우선 소재는 지하·빙하·동굴·도시·폐쇄 구역, 사막·화산·호수·실제 구조물처럼 장소·숫자·실물 장면이 즉시 떠오르는 지구 기반 이야기다.

## 제외 대상

- 단순 색깔의 이유, 이름 유래, 평범한 형성 과정
- 답이 바로 예상되는 교과서형 질문
- 구체적인 위험·반전·규모 없이 분위기만 신비로운 소재
- 무료 스톡이 많다는 이유만으로 선택한 평범한 풍경
- 동물을 주인공이나 핵심 반전으로 삼는 소재
- 초자연적 설명을 검증된 사실처럼 단정하는 소재
- 최근 14일 소재와 사실상 같은 이야기
- 제목만 다르고 핵심 대상·사건·관측값이 최근 소재와 같은 이야기

## 검증 경로

- 검색 성공: `grounded_search`
- 검색 실패 후 기존 검증 소재 사용: `verified_cache`
- 둘 다 불가능한 경우: 변하지 않는 사실만 쓰는 `model_memory`

검증 방식과 출처는 항상 `topic.json`에 기록한다.
